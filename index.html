How it works & interview talking points

The browser calls GET /api/inventory. A Python gateway sends a SOAP GetInventory request over HTTP to a separate mock ERP service. It validates XML and maps values to JSON. Prices use integer fils. The read operation has a two-second timeout and a maximum of two attempts. The outage control triggers HTTP 503. A failed sync clears stale inventory.

This is a read-only personal lab, not Dynamics AX or a company system. Stack: Python standard library, HTML, CSS and JavaScript. Production work needs authentication, a provider-specific WSDL contract, monitoring and deployment controls.
